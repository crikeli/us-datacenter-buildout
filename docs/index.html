What this is

A real pipeline built to showcase the AWS/geospatial data engineering stack named in a real job posting (S3, Glue/PySpark, Step Functions, Lambda, EventBridge, Redshift Serverless, Terraform, CI/CD) - see the repo's README for the full architecture and the Terraform module under pipeline/terraform. The AWS infrastructure ran once to produce these results and was then torn down (see README for the run evidence); this site itself is fully static.

Data sources

Facility locations, status, and capacity: FracTracker Alliance National Data Centers Tracker (free non-commercial use, credited here). Population: 2020 Census, via Microsoft Planetary Computer. Imagery: Sentinel-2 L2A, via Microsoft Planetary Computer.
